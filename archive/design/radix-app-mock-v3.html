What changed since mock v1 — and why

Every delta below traces to the evaluative study (ux-research-notes.md) or the clean-room vision (greenfield-vision.md); the mapping lives in synthesis-vision.md.

D1Brief over transcript

The unit of work is a durable, versioned, exportable artifact with a ledger stamp — auditable and shareable in a way a scroll position never is. Chat survives as the steering thread.

D2The answer never streams

Streamed prose reads as confidence before evidence exists. Radix streams the work log; the Brief composes atomically — a claim cannot render before its chip.

D3Four words, no percentages

Corroborated / Sourced / Reported / Inferred as word + fill-glyph (never color alone). The structural score lives one level down, in the witness panel.

D4The signing ceremony

Hold-to-approve (or hold Space) — deliberately never plain Enter, so approval can't become a reflex. Changed SQL requires re-approving the diff.

D6Every claim is challengeable

Challenge → the agent proposes the cheapest verification instead of defending itself. Corrections version the Brief and feed steward review.

S1Study-1 fixes baked in

In-flight grammar (active row + count-up), metadata contrast raised to AA, one deliberately Inferred claim so the tier system is learned by contrast, witness panel makes chips doors.

The D1 decision, framed

Mock v1 (chat console) is the fastest credible build and demos the agent loop beautifully. Mock v2 (this) is the clean-room architecture: stronger audit/share/version story, native home for the gate ledger and the repair loop, and the exec projection falls out for free. The honest middle — v1's build cost with v2's DNA — is the chat surface whose answer cards ARE Briefs (ids, exports, ledger stamps), graduating to this workspace as v2 of the product. Both mocks are live; compare, then call it.
