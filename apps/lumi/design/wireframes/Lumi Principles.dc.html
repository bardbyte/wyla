Lumi design principlesthe analytics agent that shows its receipts
Calm, evidentiary, never nagging. Two governing emotions rules: take as much work away from people as possible; never produce anxiety, uncertainty, or mistrust — if a surface produces one, redesign the surface.
01 Speaks only at thresholds Variations accrue quietly; the steward queue fills by invitation, never a red badge. Disambiguation asks once and remembers. Silence is the default state of a trustworthy system. see: F3 · F4 queue
02 One component everywhere The Table Profile is identical docked in chat, explorer, and cockpit. Tier chips, meridian lines, and provenance popovers share one anatomy — trust reads the same in every room. see: component sheet · F4 docked profile
03 Uncertainty is a rendered surface "What we don't know yet" is a card with a next step, not an apology. Refusals carry doors: nearest concepts, a request path, a lifecycle preview. Tiers use shape + color, never color alone. see: F2 tap-out · profile gaps card
04 Recorded as you · reversible Every human decision is attributed and undoable — the microcopy says so at the moment of action. Skip is a first-class button. No decision is ever a trap, so none produces anxiety. see: F4 decision card · F5 request
05 The flywheel is shown, not just implemented ask → variations accrue → the system proposes → one steward tap governs → the next answer cites it ●. The cockpit captions this loop so the person tapping sees why the tap matters; the ripple feed makes each approval visibly improve the graph. see: F4 ripple feed · F1 meridian line
06 Verification is a surface, not a footnote The verdict card earns the trust the number spends: default-FAIL, criteria flip true with evidence, retries render calm. see: F7 gate · component 12
07 Exploratory carries a visible passport Powerful ≠ certified, and the UI never lets them blur: watermark + banner until the contract gate passes — first-class, never second-class. see: F7 notebook · F9
08 The stream is the interface Every component consumes live events — state deltas animate one slot, pauses block inline, run end swaps theater for the answer. Nothing is a page load. see: F1 · F8
