# Executive summary

The memo shape leaders actually read. Use the document artifact.

1. Headline: the finding and its size, one sentence, no metric ids.
2. Three drivers, each one line: what moved, which way, how much of
   the change it explains. Numbers only from checked queries.
3. One risk or caveat, stated plainly — the pending definition, the
   partial period, the join you could not verify.
4. Definitions footer: each metric's meridian line, verbatim, plus
   the build id. The footer is the contract; never trim it.

Voice: plain, active, no hedging padding, no exclamation points.
If a number is exploratory, the word appears next to it, not in a
footnote.
